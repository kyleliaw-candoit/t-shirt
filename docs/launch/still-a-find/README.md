### Non-charge testing still has prerequisites

- Shopify says a paid plan must be chosen before testing a gateway. Simulated test orders are not charged, but the plan itself can create a bill. Shopify Payments test-mode setup may require out-of-scope verification; do not treat a no-charge test as authority to activate payments. [Test orders](https://help.shopify.com/en/manual/checkout-settings/test-orders)
- Printful says draft/archived Shopify products do not sync; physical products must be published on a sales channel with appropriate location/mapping. Private store access and product publication status are different controls. Verify no unintended public channel exposure. [Import requirements](https://help.printful.com/hc/en-us/articles/50262371122193-Why-don-t-my-Shopify-products-show-up-in-my-Printful-Dashboard)
- Disable automatic fulfillment in Shopify **and** verify Printful's separate automatic synced-order import is off before any test. The Printful setting can import despite Shopify auto-fulfillment being off. Mapping proof, checkout proof and paid production proof remain distinct. Never send a fulfillment request without the required charge approval. [Order processing](https://help.printful.com/hc/en-us/articles/50262336933137-How-do-I-manage-order-processing-and-fulfillment-in-Shopify)
- Shopify private mode hides store pages but displays a customizable public password landing page. Keep that surface neutral and avoid an unintended public branded launch or default email-marketing collection. Verify externally, not merely from a theme badge. [Private mode](https://help.shopify.com/en/manual/online-store/themes/password-page)
