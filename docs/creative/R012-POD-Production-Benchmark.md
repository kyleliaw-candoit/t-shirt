# R012 — Worth the Detour

## POD Production Benchmark and Provisional Standard

## 1. Purpose

This document sets the provisional production and presentation constraints for the first R012 design-development cycle.

The decision is intentionally reversible. It exists so the Creative Director can design actual shirts against a credible physical product instead of floating artwork.

The objective is not to select the permanent fulfillment stack.

The objective is to choose a realistic, commercially credible archetype that supports fair comparison across the first MVV-ready concepts.

---

## 2. Products Reviewed

### Comfort Colors 1717

Current Printful and Printify listings both support the Comfort Colors 1717 as a heavyweight, garment-dyed, relaxed-fit unisex tee.

Observed current characteristics:

- 6.1 oz/yd² / 206.8 g/m² fabric,
- 100% ring-spun cotton,
- garment-dyed / pre-shrunk construction,
- relaxed fit,
- broad color availability,
- DTG support,
- front and back print capability.

This physical character is well aligned with Worth the Detour: lived-in, substantial, casual, and credible for an audience organized around old objects, patina, discovery, and things with character.

### Bella+Canvas 3001

Current Printify listing positions the Bella+Canvas 3001 as a lighter-weight 4.2 oz/yd² retail-fit tee with very broad color and size coverage and multiple print areas.

It remains a credible lower-cost / lighter-weight POD baseline, but its cleaner, lighter retail silhouette is less naturally aligned with the first Worth the Detour expression than the Comfort Colors 1717.

---

## 3. Identity-Led Apparel Benchmark

Sloth Hiking Club is useful as a directional benchmark because it sells identity-led graphic tees at scale and currently markets its main tee on Comfort Colors.

Observed product-presentation patterns:

- Comfort Colors is part of the value proposition rather than hidden as a commodity blank,
- garment color is visually important,
- designs are shown on believable shirts rather than isolated artboards,
- product pages combine clean product imagery with richer community / customer imagery,
- the shirt is sold as a durable, comfortable object connected to an identity, not merely as a printed slogan.

This supports treating the garment itself as part of the creative proposition.

---

## 4. Provider Read

### Printify

Strengths relevant to R012:

- Comfort Colors 1717 available,
- competitive base pricing,
- network of print providers,
- realistic watermark-free mockup templates,
- flat-lay, lifestyle, and multi-angle mockup options,
- ability to upload custom mockups.

Risk for the first comparative test:

The provider-network model creates more production-choice variability. That is useful for later cost optimization, but less useful while the immediate Creative Director goal is to hold the physical product assumption stable across concepts.

### Printful

Strengths relevant to R012:

- Comfort Colors 1717 available,
- DTG front / back / sleeve support,
- product positioned explicitly as heavyweight and relaxed,
- integrated Design Maker / realistic product mockups,
- straightforward single-platform production reference for a controlled first cycle.

Printful also documents a 15 × 18 inch standard front DTG placement for supported products. Final artwork must still be checked against the specific 1717 file template before production.

### Provisional provider decision

Use **Printful as the production reference for the first R012 design-development cycle**.

This is not a permanent vendor selection and does not prevent later fulfillment through Printify or another provider.

Reason:

> **For the first creative cycle, consistency and a clear physical design constraint are more valuable than optimizing unit cost.**

---

## 5. Provisional R012 Production Archetype

### Garment

**Comfort Colors 1717 — Unisex Garment-Dyed Heavyweight T-Shirt**

### Production reference

**Printful**

### Primary print method

**DTG**

### Initial placement

**Front print only** for the first A/B/C comparison unless a concept genuinely requires another placement to preserve its meaning.

Keeping placement consistent reduces presentation noise and prevents the first test from accidentally comparing front-print versus back-print behavior rather than Creative Territory.

### Working print envelope

Design inside a conservative **12 × 15 inch working composition area** centered within the available front DTG zone.

This is a Creative Director working constraint, not a claim about the maximum provider print area. Before production, every final art file must be checked against Printful's current 1717 template / file guidelines.

### Garment color for controlled MVV presentation

Use **Ivory / a warm light neutral equivalent** as the default controlled concept-comparison color, subject to current 1717 availability at execution time.

Why:

- visually compatible with the Worth the Detour world without turning the product into faux-vintage costume,
- accommodates dark and muted ink systems,
- keeps A/B/C comparison reasonably neutral,
- avoids black-shirt contrast becoming an independent performance variable,
- aligns with the warmer garment palette already proven in identity-led casual apparel.

A concept may later receive additional garment colors for merchandising, but those should not replace the controlled primary test asset.

---

## 6. Controlled MVV Presentation Standard

For the first three advancing designs, create one primary comparison asset using the same basic merchandising treatment:

- same Comfort Colors 1717 archetype,
- same garment color,
- same front-facing or near-front garment angle,
- same crop and approximate shirt scale,
- same background treatment,
- same lighting logic,
- same image dimensions,
- no model-specific personality cues,
- no lifestyle props that favor one territory,
- no territory-specific scenic storytelling in the primary test image.

The purpose is not sterile presentation.

The purpose is to prevent the mockup from becoming the main variable.

After the controlled asset exists, each design may receive a richer secondary merchandising image suitable for storefront or later advertising use.

---

## 7. Production / Creative Guardrails

### Do

- use the heavyweight garment character as part of the design judgment,
- respect realistic chest width and print scale,
- check artwork at real shirt-viewing size,
- make sure fine details survive DTG reproduction,
- use garment and ink contrast deliberately,
- let the shirt feel owned and wearable rather than like a poster placed on fabric.

### Avoid

- oversized artwork merely because a large print area exists,
- distressed effects added only to make the shirt look 'vintage',
- tiny details that disappear at normal viewing distance,
- garment colors that overpower the Creative Territory comparison,
- mockups with dramatically different poses, models, backgrounds, or lighting across A/B/C,
- treating the provisional Printful selection as a permanent supply-chain decision.

---

## 8. Decision

For the first R012 design-development cycle:

> **Design A, B, and C as front-DTG concepts on a Comfort Colors 1717, using Printful as the provisional production reference and a warm light neutral garment as the controlled comparison standard.**

This decision is strong enough to unblock actual design execution.

It should be revisited only if:

- a chosen concept requires a materially different production method,
- current product availability changes,
- a physical sample exposes a meaningful quality problem,
- MVV or fulfillment evidence later earns a different production choice.

---

## 9. Next Creative Task

Move Territories A, B, and C into actual design execution.

For each territory:

1. choose one strongest product concept,
2. resolve the wording / visual idea,
3. design the front-of-shirt composition,
4. set realistic print dimensions inside the working envelope,
5. create the canonical production artwork,
6. create the controlled Comfort Colors 1717 mockup,
7. complete the Creative Hypothesis Map,
8. bring the three resolved shirts to founder review before MVV.

No further provider research is required before beginning those designs unless current product availability contradicts this benchmark.
