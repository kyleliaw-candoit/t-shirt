# TRACE-PILOT-002 — First Five Source Decode Cards

## Data-entry contract

This is an empty execution template. `PENDING` is a structural placeholder, not evidence, an unavailable-value reason, or a completed decision. Before checkpoint review, replace every `PENDING` with observed evidence, an analytical conclusion, or `UNAVAILABLE — <reason>`, as appropriate.

- Create a card only after its expression family has a final `ELIGIBLE` Gate 0 disposition.
- Keep observed facts separate from analytical hypotheses.
- Use exactly one primary outcome: `RECIPE-CANDIDATE`, `GRAMMAR-ONLY`, or `NO-TRANSFERABLE-MECHANISM`.
- If the outcome is `RECIPE-CANDIDATE`, complete all five mechanism-fingerprint fields.
- Populate `NONZERO_SALES_CORROBORATION` for DTC cards; outside DTC, use `N/A — non-DTC source` or a more specific reason.
- Record every source-specific transfer prohibition; `NONE OBSERVED — <basis>` is required when a category does not apply.
- Demonstrate this timestamp order for every card: `ORIGIN_SCREEN_CLOSED_AT_UTC <= FINAL_GATE0_CLOSED_AT_UTC <= SDC_CREATED_AT_UTC < CHECKPOINT_REVIEWED_AT_UTC`.
- Do not create SDC 6 or begin mechanism clustering until the independent checkpoint record is complete.
