# TRM-071 — Aging person described by an object condition report

**Operation:** Describe a person’s elapsed age and present functioning using manufacture, restoration and condition language normally applied to durable objects.

**Proposed payoff:** affectionate recognition of durability and imperfect continued functioning. This is a hypothesis about appeal, not purchase evidence.

## Essential conditions

1. A clear human age or life-stage referent.
2. Recognizable object-condition vocabulary mapped to the person, not merely a year or vintage label.
3. A readable connection between components/function and the wearer’s present condition, with an affectionate qualification where used.

**Fits when:** the audience recognizes the condition-report convention and welcomes the self-description. **Fails when:** the design only prints a birth year, or assumes all aging is improvement. This is distinct from TRM-023’s preparation/maturation claim; overlap is possible if a future expression actually does both.

**Adjustable:** age, object category and wording. **Essential execution:** preserve the person-to-object condition mapping. Typography, distressing and imagery are optional. A future brief must state the actual functional comparison before choosing decoration.

## Source grounding and copying boundary

[Source31 — Built 80 years ago](../pilots/TRACE-Etsy-60-Additional-Recipes.md#31--built-80-years-ago), listing1584939189, describes a person as original, unrestored and mostly functioning. This supports durability with a concession, not improvement through aging. Avoid the manufacture-age / original-and-unrestored / working-parts phrase sequence and close substitutions. No new concept or artwork is created in this review.

**Separate assessments:** clear relationship in the recorded source description; one source expression, so portability remains provisional. The source’s listing signal is not evidence that this operation caused purchases. Additional seller coverage is unknown beyond credited records; no rendered transfer test is claimed.
