# R012 — Fashion-First Design 1C

**Working name:** Find. Discover. Keep. — Binoculars

**Primary assortment role:** Attention / Scroll-Stop

**Secondary role:** light treasure-hunting category connection

## Founder-approved execution

This lock refers to the **refined 1C execution** approved for the fashion-first assortment round.

Locked visual decisions:

- Warm off-white / ivory garment.
- Gender-neutral presentation.
- Large, simplified binocular illustration as the dominant focal point.
- Bold charcoal / near-black ink with rust-orange as the owning accent color.
- Distressed rust block behind the binoculars creates immediate graphic impact.
- Small `WD 24` inventory-style mark remains secondary.
- Primary copy: `FIND. DISCOVER. KEEP.`
- Supporting category line: `ANTIQUES ARE WORTH THE DETOUR`.
- `EST. MMXXIV` from the earlier version is removed.
- Strong centered chest composition, approximately 11.5 in print width in the approved presentation.
- The design is intentionally fashion-first: visual desirability and small-screen impact outrank deep identity specificity.
- Front print only for the current execution.
