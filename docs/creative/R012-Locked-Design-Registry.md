# R012 — Locked Design Registry

## Purpose

This file is the canonical lock record for R012 designs that have received founder approval. It exists so approved creative decisions do not drift when work continues across chats or sessions.

**Rule:** once a design is marked `LOCKED`, do not alter it while developing another design. Any proposed revision must be treated as a new version or sibling concept.

The visual reference asset is authoritative for composition. If prose in this registry conflicts with the locked visual, the visual wins unless the founder explicitly approves a change.

---

## Concept B1 — The Detour Reflex

**Status:** `LOCKED`

**Working name:** Antiques Sign + Worth the Detour

**Creative Territory:** B — The Detour Reflex

**Core recognition:** the involuntary urge to turn off the route when an antique-shop / antique-mall sign appears.

### Locked visual decisions

- Unisex first-MVV execution; no men's/women's split yet.
- Warm off-white / ivory garment; avoid optical white.
- Clean, modern, wearable composition with generous negative space.
- Weathered roadside `ANTIQUES` sign is the primary focal point.
- Right-pointing arrow uses muted rust red.
- Dark vintage ink for the sign lettering and primary typography.
- `WORTH THE / DETOUR` remains on this shirt because it strengthens the composition.
- Product-specific wordmark treatment is the wider two-line treatment used in the approved visual; do **not** replace it with the standard three-stack brand wordmark.
- Front print only for the current MVV execution.
- Slight distressing is acceptable, but the design should not drift into dense poster illustration.

## Concept B2 — The Detour Reflex

**Status:** `LOCKED`

**Working name:** No, Really. Five Minutes.

**Creative Territory:** B — The Detour Reflex

**Core recognition:** the knowingly implausible promise an antique hunter makes after spotting an antiques sign — the sign triggers the behavior first; the line delivers the smile second.

### Locked visual decisions

- Unisex first-MVV execution; no men's/women's split yet.
- Warm off-white / ivory garment; avoid optical white.
- Same clean, modern, wearable sign language as B1.
- Weathered roadside `ANTIQUES` sign with muted rust-red right arrow remains the primary focal point.
- Copy: `No, Really. Five Minutes.`
- The reaction line is deliberately smaller than the sign so the viewing order is: **ANTIQUES sign → recognition → punchline**.
- Reaction-line typography is conversational, hand-lettered, less rigid, and less formal than the Worth the Detour wordmark.
- The phrase must not use the standard brand wordmark typography.
- Supporting muted-rust marks/underline may be used sparingly.
- Front print only for the current MVV execution.
- Slight distressing is acceptable; preserve substantial negative space.

## Brand Asset Note — Worth the Detour Wordmark

During B1 development, the compact stacked `WORTH / THE / DETOUR` typography emerged as a promising **brand wordmark candidate** for the online shop, email, and other brand materials.

This is **not yet a locked logo decision** in this registry.

## Working Rule Going Forward

Creative Director will work on **one design at a time**.

Sequence:

1. develop one concept,
2. founder reviews it,
3. if approved, mark it `LOCKED` and archive the exact visual,
4. only then move to another design.

This prevents later batch edits from accidentally changing already-approved work.
