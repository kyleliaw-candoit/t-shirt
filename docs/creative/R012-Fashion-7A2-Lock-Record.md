# R012 — Fashion-First Design 7A.2

**Working name:** Abstract Found Mark — Female-Leaning

**Primary assortment role:** Attention / Scroll-Stop

**Secondary role:** subtle antique / treasure-hunting connection through supporting copy and inventory notation

## Founder-approved execution

- Warm off-white / ivory garment.
- Female-leaning presentation.
- Large distressed taupe / warm-gray abstract brush block is the dominant visual event.
- Thin vertical rust line adds structure and fashion interest.
- Rust `WD 24` inventory-style notation remains secondary.
- Small supporting line: `THE BEST FINDS ARE WORTH THE DETOUR`.
- Minimal, contemporary composition with substantial negative space.
- The abstract mark is intentionally not literal antique imagery; the category connection is carried primarily through the small supporting line.
- Front print only for the current execution.
