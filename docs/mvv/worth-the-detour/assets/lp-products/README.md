# Worth the Detour MVV #1 — LP Product Assets

This directory stores approved customer-facing landing-page product presentation assets for MVV #1.

These files are presentation derivatives for the landing page. They do **not** replace the canonical locked T-shirt design sources in `docs/creative/assets/R012/`.

Naming convention for primary LP images:

`R012-<design_id>-LP-PRIMARY.png`

Example:

`R012-B2-LP-PRIMARY.png`
